在浏览器游戏里直接用

零依赖，import 进 canvas / Phaser / PixiJS / three.js 项目。所有特效都能传 palette 换色、flip 镜像、seed 换随机种子。

import { createFrame, createFx, composite } from "pixelfx";
import * as frostNova from "pixelfx/fx/ice/frost-nova";

const fx = createFx(frostNova, { x: 160, y: 140 });
// 每帧: fx.update(dt); fx.draw(frame); composite(frame, img.data)

导出精灵图，进任意引擎

Godot / Unity / GameMaker / LÖVE / Bevy：渲染成透明 PNG 精灵图 + Aseprite 格式 JSON（帧矩形、时长、fps、锚点）。

node tools/render.mjs ice/frost-nova --sheet   # 单个
node tools/sheets.mjs                          # 全部
node tools/render.mjs fire/torch --gif         # 看动效

自己做一个新特效

模板生成 → 渲染接触表 → 用眼睛看 → 改最差的 → 再来一轮。规则见 docs/AUTHORING.md，Claude Code 还有配套 skill。

node tools/new.mjs arcane/my-spell --loop
node tools/render.mjs arcane/my-spell   # 看图
node tools/check.mjs arcane/my-spell    # 体检

本页需要通过 HTTP 打开（ES module 限制）：在仓库根目录运行 node tools/serve.mjs，然后访问 http://localhost:8080/index.html。完整交互版画廊在 /gallery/（点击特效可调色板、背景、导出精灵图）。目录全文见 docs/CATALOG.md。
